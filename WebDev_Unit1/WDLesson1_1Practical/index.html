Web Technologies

HTML

HTML is a markup tool used to help create webpages. It brings in elements to help design and organize webpages. It builds the skeleton of a site.

CSS

CSS is a programming tool used to design and present webpages. CSS is used to change the fonts or colors of a webpage. It is one of the main tools used on the world wide web.

Javascript

javascript is a high level programming tool thats used to make interactive aspects of a webpage. It's used to add stuff such as visual effects or animations. Its used alongside css and html on the world wide web
